# databrick_trabajo_final
trabajo final de curso databrick de smartdata
file datasets - se recolecto data de informacion de un supermercado registrando las ventas que tienen por año, ordenado con departamentos y productos vendidos
file reversion - carpeta realizada para poder eliminar las tablas silver que se hayan creado en caso no se complete toda la ETL hasta la capa de oro
file seguridad - carpeta donde se guarda el codigo para brindar grants a usuarios y grupos a las tablas creadas del ETL
file prep.amb - creacion de catalogo, esquemas, tablas, external location, lo necesario para que se pueda implementar el ETL. esta el archivo en formato SQL
file proceso - notebook de ETL, es recomendable hacer un notebook por capa
file certificaciones - poner la foto de el certificado y el enlace
file evidencias - captura de como se desarrollo, el github, en asure, databricks, etc.
